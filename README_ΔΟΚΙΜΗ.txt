PC LAB 3D - REAL 3D TEST

1. Χρειάζεται Node.js 22 ή νεότερο.
2. Κάνε διπλό κλικ στο START_PC_LAB_3D.bat.
3. Την πρώτη φορά το npm ci μπορεί να χρειαστεί λίγα λεπτά.
4. Ο browser ανοίγει ΜΟΝΟ όταν ο 3D server απαντήσει πραγματικά.
5. Αν υπάρξει σφάλμα, το παράθυρο μένει ανοικτό και εμφανίζει το μήνυμα/log. Στείλε screenshot του παραθύρου.

Διεύθυνση δοκιμής: http://127.0.0.1:5173/
